# Allen Coral Atlas Class Descriptions

This page provides the full class descriptions and colour schemes used
by ReefMappeR for benthic habitat and geomorphic zone mapping, following
the [Allen Coral Atlas](https://allencoralatlas.org) classification
system.

Full methodology:
[allencoralatlas.org/methods](https://allencoralatlas.org/methods/)

------------------------------------------------------------------------

## Geomorphic Zones

| Value | Colour | Class | Description |
|----|----|----|----|
| 11 |   | Shallow Lagoon | A shallow, enclosed or semi-enclosed, sheltered, shallow-bottomed area dominated by sediments. |
| 12 |   | Deep Lagoon | A sheltered, broad body of water, semi- or fully enclosed by reefs. Variable depth with soft bottom dominated by reef sediment. |
| 13 |   | Inner Reef Flat | A low-energy, sediment-dominated, horizontal to gently sloping platform behind the Outer Reef Flat. |
| 14 |   | Outer Reef Flat | Adjoins the seaward margin of the reef; a planar, broad and shallow platform with strong wave-driven zonation. |
| 15 |   | Reef Crest | A zone marking the boundary between the reef flat and reef slope. Typically shallow with highest wave energy absorption. |
| 16 |   | Terrestrial Reef Flat | A broad, flat area of fringing reef directly connected to land, exposed to freshwater runoff, nutrients and sediments. |
| 21 |   | Sheltered Reef Slope | A submerged, sloping area extending into deep water, sheltered from prevailing wind or current. |
| 22 |   | Reef Slope | A submerged, sloping area extending from the reef crest toward the shelf edge. |
| 23 |   | Plateau | A deeper, submerged reef feature with hard bottom, oriented horizontally or gently sloping seaward. |
| 24 |   | Back Reef Slope | A complex, inner, gently sloping reef zone behind the Reef Flat, sediment-dominated with coral outcrops. |
| 25 |   | Patch Reef | A small, free-standing coral reef within a lagoon, rising from a sandy area. |

## Benthic Habitats

| Value | Colour | Class | Description |
|----|----|----|----|
| 11 |   | Sand | A soft substrate dominated primarily by fine, unconsolidated sediments. |
| 12 |   | Rubble | A habitat of loose, coarse fragments of broken reef material. |
| 13 |   | Rock | Any exposed surface of hard, bare substrate. |
| 14 |   | Seagrass | Habitats where seagrass is the dominant biota. |
| 15 |   | Coral/Algae | Any hard substrate area where living corals and/or algae are growing. |
| 18 |   | Microalgal Mats | Visible accumulations of microscopic algae within sandy sediments. |
